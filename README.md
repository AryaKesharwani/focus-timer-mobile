# Focus Timer

A React Native focus timer with a SwiftUI Live Activity for the iOS Dynamic Island and lock screen. Built with Expo SDK 54.

## Features

- Adjustable session length (15 / 25 / 30 / 45 / 60 minutes)
- Full Pomodoro cycle — short break after each focus session, long break after every fourth
- Optional task labels saved with each completed session
- Stats screen — today's count, day streak, all-time focus time, 7-day chart, recent sessions
- Ambient sound during focus (rain / forest / white noise)
- Local notification + sound when a session ends, even when the app is backgrounded or the phone is locked
- Persistent history via AsyncStorage
- iOS Live Activity — countdown ring in the Dynamic Island and a pill on the lock screen with progress bar and live timer

## Requirements

- Node.js 20+
- macOS with Xcode 15+ (for iOS development)
- CocoaPods (`brew install cocoapods`)
- iOS 16.2+ device or simulator for Live Activities; Dynamic Island requires an iPhone 14 Pro or newer

## Setup

```bash
npm install
npx pod-install ios
```

## Run

### iOS simulator (recommended for Live Activity testing)

```bash
npx expo run:ios --device "iPhone 17 Pro"
```

Pick a Pro-model simulator to see the Dynamic Island.

### iOS device

Open `ios/FocusTimer.xcworkspace` in Xcode, set your team under Signing & Capabilities for both the `FocusTimer` and `FocusTimerWidget` targets, plug in the phone, and press Run.

### Android

```bash
npx expo run:android
```

(The Live Activity is iOS-only; the rest of the app works on Android.)

## Testing the Live Activity

1. Start a focus session in the app.
2. Lock the simulator (`Cmd+L`) — the pill appears on the lock screen.
3. Send the app to the background (`Cmd+Shift+H`) — the Dynamic Island shows the icon and countdown. Long-press for the expanded view.
4. Pausing in the app updates the pill to "Paused"; reset or break completion dismisses it.

If the pill does not appear, check Settings → Focus Timer → Live Activities is enabled.

## Project structure

```
App.tsx                              # Single-screen React Native UI
modules/live-activity/               # Local Expo module bridging JS to ActivityKit
  ios/LiveActivityModule.swift       # start / update / end exposed to JS
  ios/FocusTimerAttributes.swift     # ActivityAttributes shared with widget
targets/widget/                      # WidgetKit extension (added via @bacons/apple-targets)
  FocusTimerLiveActivity.swift       # Dynamic Island + lock screen layouts
  FocusTimerAttributes.swift         # Identical copy used by the widget process
ios/                                 # Generated by `npx expo prebuild` — git-ignored
```

## Notes

- The ambient sound URLs in `App.tsx` point at public Pixabay CDN files. They may not always be reachable; swap them for local `require()`'d MP3s if you want offline playback.
- The Live Activity is gated at runtime by `@available(iOS 16.2, *)`; the pod's deployment target stays at 15.1 so the rest of the app still installs on older iOS versions.
